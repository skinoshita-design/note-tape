# ノートテープ — 音声文字起こし・要約アプリ

講義や会話の音声ファイルを、Gemini APIで文字起こし→要約まで一気通貫で行うシンプルなWebアプリです。
保存や共有機能は持たず、その場で結果を確認・コピーして使う「最小機能」構成です。

- 入力：講義名（任意）＋音声ファイル
- 出力：文字起こし全文／要約文＋要点（3〜5個）
- どちらもワンタップでコピー可能

詳しい仕様は [`docs/SPEC.md`](docs/SPEC.md)、使用APIの詳細は [`docs/API_NOTES.md`](docs/API_NOTES.md) を参照してください。

## 動作環境

- モダンブラウザ（Chrome / Edge / Safari 最新版を推奨）
- インターネット接続（Gemini APIへの通信のため）
- Gemini APIキー（自分で発行、後述）
- サーバー・ビルド環境は不要（静的HTML1ファイルのみで動作）

## セットアップ

### 1. Gemini APIキーを取得する

1. [Google AI Studio](https://aistudio.google.com/apikey) にGoogleアカウントでログイン
2. 「Create API key」からキーを発行（無料枠あり、クレジットカード登録不要）

### 2. アプリを起動する

以下のいずれかの方法で使用できます。

**方法A：ローカルで開く**

1. このリポジトリをダウンロード（または `git clone`）
2. `index.html` をブラウザで直接開く

**方法B：GitHub Pagesで公開する**

1. このリポジトリを自分のGitHubアカウントにpush
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」に設定し、ブランチを `main`、フォルダを `/ (root)` に指定
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能になる

### 3. 初回起動時にAPIキーを入力する

アプリを開くと自動的にAPIキー入力用のモーダルが表示されます。手順1で取得したキーを貼り付けて「保存する」を押してください。
キーはこの端末のブラウザ内（`localStorage`）にのみ保存され、外部のサーバーには送信されません（Gemini APIへ直接送信されるのみ）。

キーは画面右上の歯車アイコンからいつでも変更・削除できます。

## 使い方（最短導線）

1. 講義名（任意）を入力する
2. 「タップしてファイルを選択」から音声ファイルを選ぶ（30秒〜2分程度を推奨）
3. 「実行する」を押す
4. 文字起こしが表示される（コピー可能）
5. 続けて要約・要点が表示される（コピー可能）

## 注意事項

- **個人情報・機密情報を含む音声はアップロードしないでください**。講義の短いサンプル音声などでお試しください
- 音声・文字起こし・要約はどこにも保存されません。ページを閉じる／リロードすると消えます
- APIキーはブラウザから直接Gemini APIに送信されるため、ブラウザの開発者ツールを使えば本人には見える状態になります。他人と共有するURLで公開する場合は、それぞれが自分自身のAPIキーを入力して使う前提です（開発者のキーを埋め込んで公開しないこと）
- Gemini API利用には無料枠がありますが、利用量制限があります。詳細は [`docs/API_NOTES.md`](docs/API_NOTES.md) を参照してください
