# screenshots/

`docs/TESTCASES.md` の各テストケースに対応する動作証跡のスクリーンショットをここに格納してください。
ファイル名は `TESTCASES.md` の「証跡」欄に記載した名前に合わせています。

| ファイル名 | 対応テスト |
|---|---|
| `01_apikey_modal.png` | TC01：初回起動時のAPIキー入力モーダル |
| `02_apikey_saved.png` | TC02：APIキー保存後、リロードしても再表示されないこと |
| `03_file_selected.png` | TC03：講義名・音声ファイル選択後の画面 |
| `04_transcript_result.png` | TC04：文字起こし結果の表示 |
| `05_summary_result.png` | TC05：要約・要点の表示 |
| `04-05_transcript_and_summary_pc.png` | **（取得済み）** TC04・TC05：PCでの文字起こし〜要約結果（世界史A、1枚に両方収録） |
| `06_copy_success.png` | TC06：コピー成功時の表示（「コピーしました」） |
| `07_mobile_view.png` | TC07：スマホ幅での表示 |
| `08_no_apikey.png` | TC08：APIキー未入力時の挙動 |
| `09_invalid_key_error.png` | TC09：不正なAPIキー時のエラー表示 |
| `10_no_file_error.png` | TC10：音声ファイル未選択時の挙動 |

**注意**：スクリーンショットには、講義名や音声内容など個人情報・機密情報が写り込んでいないか必ず確認してから提出してください。
